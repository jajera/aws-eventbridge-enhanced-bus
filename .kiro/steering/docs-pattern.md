# Docs pattern

- Overview: hero + at-a-glance + path cards
- Patterns: classic vs enhanced; UNORDERED vs FIFO (story, not a dump)
- Design: resource diagram, RAM, EventGroupId, alert rules table
- Demo: operator walkthrough; commands in `<div class="run" markdown>` blocks
- References: dated links only

Prefer tables and mermaid over long prose. Keep IoT details minimal — feed only.
